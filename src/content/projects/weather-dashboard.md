An interactive weather dashboard that displays current conditions, 7-day forecasts, and historical weather data with beautiful chart visualizations.

## Key Features
- Interactive weather maps
- 7-day forecast with hourly breakdown
- Historical weather data charts
- Location search with autocomplete

## Tech Stack
- **Frontend**: TypeScript, Chart.js
- **APIs**: OpenWeather API, Mapbox
