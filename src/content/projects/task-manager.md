A comprehensive task management application built with React and Node.js. Features include real-time updates via Socket.io, team collaboration, drag-and-drop task organization, and customizable workflows.

## Key Features
- Real-time task updates across team members
- Drag-and-drop Kanban board
- Custom workflow automation
- Role-based access control
- File attachments and inline comments

## Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, Socket.io
- **Database**: PostgreSQL with Prisma ORM
