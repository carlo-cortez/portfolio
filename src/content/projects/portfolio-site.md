A fast, modern portfolio built with Astro and Tailwind CSS. Features a content management system for easy project updates via an admin UI.

## Key Features
- Lightning-fast static site generation
- Admin UI for content management (Decap CMS)
- Tag-based project filtering
- Dark / light mode
- Fully responsive design
